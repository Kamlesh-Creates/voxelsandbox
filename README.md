# Voxelsandbox

A Unity project for experimenting with voxel-based gameplay and world systems.

## Requirements

- Unity `6000.6.3f1`
- Git

## Getting started

1. Clone the repository:

   ```bash
   git clone https://github.com/Kamlesh-Creates/voxelsandbox.git
   cd voxelsandbox
   ```

2. Open the project in Unity Hub using Unity `6000.6.3f1`.
3. Open a scene from `Assets/Scenes/` and press **Play**.

Unity will recreate generated folders such as `Library/` the first time the project opens.

## Project structure

- `Assets/` - scenes, scripts, materials, prefabs, textures, and other project assets
- `Assets/Scripts/` - gameplay and voxel systems
- `Packages/` - Unity package manifest and lock file
- `ProjectSettings/` - Unity project configuration

Build output, editor caches, logs, and other generated files are excluded through [`.gitignore`](.gitignore).
